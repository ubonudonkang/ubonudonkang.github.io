DORMANT REOPENING TEMPLATE — BA Bridge enrolment flow

This is reference source, stored as plain text so it cannot run as a website page.
It contains the enrolment form. Its behaviour (saving to Apps Script, opening
Selar, restoring a payment return) lives in js/forms.js and is driven by the
data-* attributes on the form.
Use open_ba_registration.mjs with complete cohort details to render it.

Check the deployed Apps Script, Selar product price and post-purchase return URL
before publishing. A browser return is not payment proof.
